ABOUT THIS PROJECT

Sign in with MuseAI.

This repository pairs a static sign-in concept with a copyable OAuth + PKCE client example.

What is real today?

The static pages and integration example run locally. The OAuth Worker deliberately returns HTTP 503 because the server-side authorization, token, JWKS, and signed Muse approval implementation is not included.

No email/password collection, Supabase signup form, or simulated authenticated state is used in this sign-in demo.
