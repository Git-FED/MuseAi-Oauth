# Security policy

This project is a non-production scaffold. Do not submit real credentials, private keys, access tokens, or personal data. Do not deploy it or connect real accounts.

For a private security report, contact the project maintainer through an independently verified private channel. There is no bug bounty or production service currently associated with this repository. Never open a public issue containing exploit details or secrets.

All changes must fail closed, include tests, and avoid logging tokens, codes, signatures, verifiers, or full email addresses.
